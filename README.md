# ASPIRE Quantum Sensing Mini-Workshop 2026

A minimal static website for the ASPIRE Quantum Sensing Mini-Workshop, held October 22–23, 2026 at Fermilab.

## Files

- `index.html` — home page (overview, dates, venue, contact)
- `schedule.html` — program schedule
- `speakers.html` — speaker list
- `participants.html` — expected participants
- `styles.css` — shared stylesheet
- `images/` — put `logo.png` (and any other images) here

## Editable elements

- Contact email and organizer names (`index.html`)
- Venue name / address (`index.html`)
- Talk titles marked "Title TBD" once finalized (`schedule.html`)
- Speaker and participant lists as they are confirmed (`speakers.html`, `participants.html`)
- Logo image at `images/logo.png`

## Publish to GitHub Pages

1. Create a new GitHub repository (e.g. `aspire_qsensing2026`).
2. Upload all files in this folder to the repository (keep the `images/` folder).
3. In the repository, go to **Settings → Pages**.
4. Under "Build and deployment", set **Source** to "Deploy from a branch", choose the `main` branch and `/ (root)` folder, then save.
5. GitHub will publish the site at `https://<your-org-or-username>.github.io/<repo-name>/`.
